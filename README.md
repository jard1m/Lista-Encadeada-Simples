# Lista Encadeada Simples — Cadastro de Pessoas

Exercício da disciplina de Algoritmos e Programação, curso de Ciência da Computação.
Universidade do Vale do Itajaí, professor de algoritmos II Andrigo Borba.

## Sobre o exercício

Programa em C++ que guarda o nome e o peso de várias pessoas usando uma lista encadeada simples.
Numa lista encadeada, cada pessoa fica guardada num "nó", e cada nó aponta para o próximo, como os vagões de um trem. Assim, a lista pode crescer conforme novas pessoas são cadastradas.

## O que o programa faz

- Cadastra pessoas com nome e peso
- Conta quantas pessoas foram cadastradas
- Soma os pesos de todas as pessoas
- Calcula a média dos pesos
- Mostra as pessoas com peso abaixo de 50 kg
- Procura uma pessoa pelo nome

## Arquivos

- main.cpp — início do programa
- pessoas.h — lista das funções
- pessoas.cpp — código completo das funções

## Como compilar e rodar

g++ main.cpp pessoas.cpp -o programa
./programa

## O que aprendi

- Criar e percorrer uma lista encadeada usando ponteiros
